# Шахматная школа «У моста»

Готовый статический сайт: Орёл, улица Ленина, 13. Установка пакетов и сборка не нужны.

## Обновление сайта по прежнему адресу

Адрес сайта: https://t8byw7ykgw-droid.github.io/u-mosta/
Репозиторий: https://github.com/t8byw7ykgw-droid/u-mosta

1. Распакуйте архив `u-mosta-counters.zip` на компьютере.
2. Войдите в GitHub с правом записи в указанный существующий репозиторий и откройте его вкладку Code. Выберите ветку `main`.
3. Над списком файлов нажмите Add file → Upload files. Загрузите все 11 файлов из распакованного архива. Загружайте сами файлы в корень репозитория, а не ZIP и не внешнюю папку. `index.html`, остальные пять HTML-страниц, `style.css`, `main.js`, `logo.svg`, `opera-board.svg` и `README.md` должны лежать рядом.
4. Введите сообщение `Обновить счётчики аналитики`, выберите Commit directly to the main branch и нажмите Commit changes. Одноимённые файлы будут обновлены; предыдущие версии останутся в истории GitHub.
5. Откройте Settings → Pages. Для этого комплекта файлов нужны Source: Deploy from a branch, Branch: main, Folder: /(root). Если уже указаны эти значения, оставьте их; при изменении нажмите Save.
6. Дождитесь успешного завершения публикации во вкладке Actions. Обновление может занять до 10 минут. Затем откройте https://t8byw7ykgw-droid.github.io/u-mosta/ и выполните принудительное обновление страницы: Ctrl+F5 в Windows или Cmd+Shift+R в macOS.
7. Проверьте переходы по всем шести страницам. Для сохранения адреса обновляйте именно этот репозиторий в прежнем аккаунте с прежним названием `u-mosta`.

## Файлы сайта

- index.html — главная, историческая шахматная позиция.
- napravleniya.html — курсы. Имя файла сохранено для совместимости ссылок.
- trenery.html — тренеры.
- raspisanie.html — расписание.
- ceny.html — тарифы и условия абонементов.
- kontakty.html — адрес, карта и форма.
- style.css — оформление всех страниц.
- main.js — меню, фильтры расписания, форма, текущий год.
- logo.svg — логотип.
- opera-board.svg — шахматная доска на главной странице.

## Как обновлять

Отредактируйте нужный файл и загрузите его через Add file → Upload files, затем Commit changes. GitHub Pages автоматически опубликует изменения из main. Для изменения цен правьте ceny.html; расписания — raspisanie.html; тренеров — trenery.html. Серверная часть не нужна.

## Подключённые счётчики

Во все шесть страниц встроены предоставленные коды: Top.Mail.Ru (3806859), Top100 (проект 7753159), LiveInternet (отправка просмотра через new Image). Каждый код присутствует на странице один раз. При включённом JavaScript эти коды не показывают видимые значки. Для Top.Mail.Ru и Top100 сохранены блоки noscript. Повторно добавлять эти коды не нужно.

Для работы кодов при просмотре сайта разрешите JavaScript. Для проверки временно отключите блокировщик рекламы для сайта, откройте опубликованный адрес и перейдите на несколько страниц. Проверьте поступление посещений в кабинетах Top.Mail.Ru, Top100 и LiveInternet. Отсутствие значков на странице ожидаемо для присланных кодов и само по себе не означает отсутствие статистики. Фактический приём данных проверяется после публикации в кабинетах сервисов.

## Публикация на Netlify

Распакуйте архив в папку, внутри которой сразу лежит index.html. Войдите в Netlify. Для нового проекта откройте https://app.netlify.com/drop и перетащите папку в область загрузки. Для обновления уже созданного проекта откройте его Deploys и перетащите туда всю обновлённую папку. Дождитесь статуса Published. Не загружайте только изменённые файлы: при ручной публикации нужен полный комплект сайта.

## Форма и карта

Форма работает как согласованный макет: показывает «заявка принята» и очищает поля, но не передаёт данные администратору и не сохраняет их. Публикация на GitHub Pages не подключит отправку автоматически. Для реальных заявок требуется отдельный сервис обработки формы и изменение main.js.

Карта загружается из Яндекс Карт при наличии интернета; рядом есть ссылка на поиск адреса. Коды счётчиков аналитики подключены; приём посещений проверяется в кабинетах сервисов.

## Если сайт не открылся

- Проверьте, что файл называется именно index.html и лежит в корне main, а не во вложенной папке.
- Убедитесь, что в Settings → Pages выбраны main и /(root).
- Проверьте статус публикации во вкладке Actions.
- Если HTML открылся без оформления, проверьте, что style.css загружен рядом с index.html и имя файла совпадает по регистру.
- После обновления выполните принудительное обновление страницы: Ctrl+F5 (Windows) или Cmd+Shift+R (macOS).
