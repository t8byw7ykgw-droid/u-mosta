# Шахматная школа «У моста»

Готовый статический сайт: Орёл, улица Ленина, 13. Установка пакетов и сборка не нужны.

## Публикация на GitHub Pages через браузер

1. Войдите в GitHub и создайте новый репозиторий с названием `u-mosta`. Выберите Public (для бесплатного GitHub Pages), включите Add README и нажмите Create repository.
2. Распакуйте ZIP на компьютере. В репозитории нажмите Add file → Upload files.
3. Загрузите файлы из архива, а не сам ZIP и не внешнюю папку. `index.html`, остальные HTML-страницы, `style.css`, `main.js` и `logo.svg` должны находиться непосредственно в корне репозитория. README.md можно заменить приложенной инструкцией.
4. Нажмите Commit changes и сохраните файлы в ветку main.
5. Откройте Settings → Pages. В разделе Build and deployment выберите Source: Deploy from a branch, Branch: main, Folder: /(root), затем Save.
6. Дождитесь публикации (изменения могут появляться до 10 минут). В Settings → Pages нажмите Visit site. Для репозитория u-mosta адрес обычно имеет вид https://ВАШ-ЛОГИН.github.io/u-mosta/.
7. Проверьте переходы по всем шести страницам, карту, фильтры расписания и форму.

Если используете уже существующий репозиторий, сначала сохраните его прежние файлы. Загрузка одноимённых файлов заменит старую версию.

## Файлы сайта

- index.html — главная, историческая шахматная позиция.
- napravleniya.html — курсы. Имя файла сохранено для совместимости ссылок.
- trenery.html — тренеры.
- raspisanie.html — расписание.
- ceny.html — тарифы и условия абонементов.
- kontakty.html — адрес, карта и форма.
- style.css — оформление всех страниц.
- main.js — меню, фильтры расписания, форма, текущий год.
- logo.svg — логотип.

## Как обновлять

Отредактируйте нужный файл и загрузите его через Add file → Upload files, затем Commit changes. GitHub Pages автоматически опубликует изменения из main. Для изменения цен правьте ceny.html; расписания — raspisanie.html; тренеров — trenery.html. Серверная часть не нужна.

## Подключённые счётчики

Во все шесть страниц уже встроены предоставленные коды: LiveInternet (licnt0C19), Top100 (проект 7753158), Top.Mail.Ru (3806829). Каждый код присутствует на странице один раз. LiveInternet показывает значок; остальные два кода не предусматривают видимый значок при включённом JavaScript. Повторно добавлять эти коды не нужно.

## Публикация на Netlify

Распакуйте архив в папку, внутри которой сразу лежит index.html. Войдите в Netlify. Для нового проекта откройте https://app.netlify.com/drop и перетащите папку в область загрузки. Для обновления уже созданного проекта откройте его Deploys и перетащите туда всю обновлённую папку. Дождитесь статуса Published. Не загружайте только изменённые файлы: при ручной публикации нужен полный комплект сайта.

## Форма и карта

Форма работает как согласованный макет: показывает «заявка принята» и очищает поля, но не передаёт данные администратору и не сохраняет их. Публикация на GitHub Pages не подключит отправку автоматически. Для реальных заявок требуется отдельный сервис обработки формы и изменение main.js.

Карта загружается из Яндекс Карт при наличии интернета; рядом есть ссылка на поиск адреса. Коды счётчиков аналитики подключены; приём посещений проверяется в кабинетах сервисов.

## Если сайт не открылся

- Проверьте, что файл называется именно index.html и лежит в корне main, а не во вложенной папке.
- Убедитесь, что в Settings → Pages выбраны main и /(root).
- Проверьте статус публикации во вкладке Actions.
- Если HTML открылся без оформления, проверьте, что style.css загружен рядом с index.html и имя файла совпадает по регистру.
- После обновления выполните принудительное обновление страницы: Ctrl+F5 (Windows) или Cmd+Shift+R (macOS).
